# 🏦 Banking Credit Risk Power BI Dashboard

**Dashboard project analyzing credit risk KPIs in the banking sector using Power BI.**

---

## 📋 Overview

A comprehensive data analytics dashboard providing actionable insights into loan origination, approvals, and credit risk analysis for a banking institution. This project demonstrates advanced Power BI development with complex DAX calculations and interactive visualizations.

**Key Insight:** Analyze NPA ratios, loan approval rates, and customer risk segmentation to make data-driven decisions.

## 🎯 Key Performance Indicators (KPIs)

- **NPA Ratio** - Non-Performing Assets analysis for risk assessment
- **Good Loan vs Bad Loan Approval Rate** - Lending quality metrics
- **Charged-Off Loans** - Applications that resulted in charge-offs
- **Customer Risk Segmentation** - Classification of borrowers by risk level
- **Approval Trends** - Month-over-month loan approval patterns
- **Default Analysis** - Historical default patterns and predictive metrics

## 🔧 Technical Highlights

### DAX Measures Implemented
- NPA Ratio (%) = Non-Performing Assets / Total Assets
- Approval Rate = Approved Loans / Total Applications
- YoY Growth = (Current Year - Previous Year) / Previous Year
- Risk Score Calculation with multi-factor weighting

### Data Model
- Star Schema with Fact and Dimension tables
- Optimized relationships for performance
- Role-based row-level security (optional)
